# World Happiness Report 2019 — Data Analysis

Exploratory analysis of the 2019 World Happiness Report using Python and pandas.

## What I did
- Cleaned and validated the dataset (checked for missing values and duplicates)
- Ranked countries by happiness score to find the highest and lowest scoring countries
- Ran a correlation analysis to identify which factors most influence happiness

## Key findings
- **Top 3 happiest countries:** Finland, Norway, Denmark
- **Bottom 3:** Burundi, Central African Republic, South Sudan
- **Strongest driver of happiness:** GDP per capita (correlation of 0.80 with Score), followed by social support and freedom to make life choices

## Tools used
- Python, pandas, matplotlib
- Google Colab
- AI tools (for debugging, validating code, and catching an analysis error before it reached the final results)

[World Happiness Report — Kaggle](https://www.kaggle.com/datasets/unsdsn/world-happiness)
